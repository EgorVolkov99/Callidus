# Callidus: Система автоматической генерации технической документации

**Callidus** — это REST API сервис на базе FastAPI для автоматизированного потокового создания сложной технической документации (Паспорта изделий, Руководства по эксплуатации) в форматах DOCX и PDF на основе структурированных JSON-данных.

## 🚀 Ключевые возможности
* **Продвинутая генерация таблиц:** Кастомная фабрика `TableFactory`, работающая напрямую с OOXML (ECMA-376). Поддерживает жесткую фиксацию ширины колонок (dxa), вертикальный текст (`btLr`), объединение ячеек и автоматическое разбиение широких таблиц (например, таблиц сварных швов) на несколько частей.
* **100% стабильность файлов Word:** Решена классическая проблема повреждения DOCX-файлов (ошибка `-2147352567`) за счет строгой сортировки XML-тегов `tblPr` и `tcPr`.
* **Умный адаптер данных:** Автоматическое транспонирование и "выпрямление" глубоко вложенных JSON-объектов в плоские массивы для рендеринга.
* **Конвертация в PDF:** Встроенный пайплайн для бесшовного преобразования DOCX в PDF с использованием `docx2pdf`.
* **Валидация:** Строгая проверка входящих данных с помощью Pydantic моделей.

## 🛠 Технологический стек
* **Backend:** Python 3.10+, FastAPI, Uvicorn
* **Генерация документов:** `docxtpl` (Jinja2), `python-docx`
* **Конвертация:** `docx2pdf` (требует установленного MS Word на сервере/ПК)
* **Валидация данных:** Pydantic
